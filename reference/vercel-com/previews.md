# Vercel - Preview Deployments product page reference

## Structure
- Single-feature page, 9 sections: hero with a chip row of toolbar features (Comments, CMS Drafts, Accessibility, Share, Feature Flags, Collaborators, Layout Shift), a "zero-config to deploy" Git-integration block with a mock PR bot comment, then six feature blocks (one H2 + one sentence + a UI mockup each), an "all environments" strip, and a two-button closing CTA.
- Depth: shallow per feature. Each block is a verb-led heading and a single sentence; the UI mockup carries the explanation (comment threads, flag overrides, accessibility audit rows, layout-shift replay with CLS scores).
- Copy to screenshots: 25 images; mockup-dominant, roughly 30% copy.
- No tabs, no accordion, no FAQ, no quotes, no stats.
- Hand-off: no in-body cross-links to other products; the footer (Agent Stack / Core Platform / Security / Tools columns) is the only navigation to Observability, Fluid, Security, CDN.
