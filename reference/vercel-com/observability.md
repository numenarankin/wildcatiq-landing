# Vercel - Observability product page reference

## Structure
- Single-product page with sub-products, about 11 sections: hero with a live-looking traffic/alert mockup, then one H2 per capability (Anomaly detection, Framework-aware insights, Debugging/Query, Logs, Instrumentation/OTEL, "Break out of the black box" 3-pillar block), then two sibling products folded in (Web Analytics, Speed Insights), and a closing "Inspect your app" CTA.
- Depth: each capability is an H2, one sentence, and a dense dashboard mockup whose labels do the explaining (routes, status codes, log rows, trace timings, Core Web Vitals). Plan tags (Pro, Enterprise, All Plans) sit on sections.
- Copy to screenshots: 7 real images but many inline HTML mockups; about 30% copy.
- No tabs, no accordion, no FAQ, no quotes. One embedded code snippet (custom event tracking).
- Hand-off: "View integrations" (/integrations#analytics) and the footer; Web Analytics and Speed Insights are presented as parts of Observability rather than linked out.

## Title and meta
- Title: Observability
- Meta description: Monitor, debug, and optimize your web applications with Vercel Observability.

- Headline: Understand production from the inside out
- Subhead: With real-time infrastructure and traffic insights, Vercel is the mission control for frontend applications.

## Section: Proactive Anomaly Detection and Alerting (Pro, Enterprise)
- See traffic spikes and usage anomalies to pinpoint and resolve issues before they impact users.

## Section: Framework-aware insights (All Plans)
- App usage and performance metrics, in a way that mirrors your app structure.
- Mockup: Function Invocations by 2xx/4xx; Route / Error Rate / Latency / Requests table (/app/[team]/projects, /app/[team]/[project]/overview, /blog/[slug], /pricing)
- Real data points collected from your users' devices for an authentic evaluation of their experiences.

## Section: Quick, accurate debugging
- Detect and diagnose issues in your web applications by surfacing errors, traffic, and performance data with custom queries and visualizations.
- Mockup: "429 Status Codes by Host, Path" (test.acme.co /demo; chat.acme.co /api/chat; sdk.acme.co /api/prompt)
- Track and analyze site performance. View metrics for different parts of your site in the Vercel dashboard. Use example queries to resolve issues and optimize your projects.
- Query builder mockup: Edge requests, Count, Last 12 hours, Group by Project, Filter Project is ACME Site
- Create queries to debug and optimize bandwidth, errors, performance, and bot traffic issues.

## Section: View, search, inspect
- Understand your application behavior with a view of all logs generated by every function in every deployment environment.
- Log mockup: 2M logs total found; rows with Time / Host / Request / Message (e.g. /api/create "Wrote 5 entries to database.", /api/feature-flags "[FetchError]: Failed to load data", /api/jwt "Expired. Generating new token...")
- View all runtime logs generated by Vercel's infrastructure across all environments.
- Trace mockup: GET /blog-posts 217ms, GET /post/1 110ms, GET /track-view 38ms. See the status, duration, URL, and a trace for each outgoing request.
- Copy share URL / Export to CSV / Export to JSON. Inspect and share your runtime logs without any third-party integrations.

## Section: Instrument, collect, and send data with flexibility
- Use your favorite tools. With OpenTelemetry (OTEL), send traces from your functions to application performance monitoring (APM) vendors. (Datadog, New Relic, More...)
- CTA: View integrations (/integrations#analytics)
- Log Drains. Share data with your favorite logging provider for advanced alerting. (mockup: acme-site 4,815,162 Logs)

## Section: Break out of the black box
- Prevent regressions. Ship new work without breaking customer experiences, and know exactly where to iterate after.
- Proactively defend. Track anomalies to shut down threats as they happen with advanced monitoring.
- Total transparency. Monitor application performance and investigate issues in the Vercel dashboard.

## Section: Understand your engagement (Web Analytics)
- View website visitor data by topic page, referrer, location, operating system, and browser.
- First-party, privacy-friendly. Data sent through your domain to avoid ad blockers.
- Find your top performers. Identify your best sources and most effective content.
- Code snippet: track('Signup', { location: 'Hero' }) from @vercel/analytics. Track custom events without third-party scripts, for Pro and Enterprise.
- Web Analytics Plus: UTM parameters, more events, and longer report windows.

## Section: Real users, real metrics (Speed Insights)
- See how your site performs for actual visitors across devices, networks, and regions.
- Mockup: Last 7 Days; P75/P90/P95/P99; First Contentful Paint 1.01s (-30%); Poor (5): /faqs, /campaign; To Improve (12): /support, /holidays; Great (100+): /home, /buy; Real Experience Score 99 (+25%): The combined score of your Web Vitals experienced by your visitors. LCP 1.42, CLS 0.02.
- Understand Core Web Vitals like First Contentful Paint, Largest Contentful Paint, Cumulative Layout Shift.

## Section: Inspect your app (closing CTA)
- Closing block (CTA buttons not captured in text; hero CTAs are Deploy now / Get a demo).
