# Vercel - AI apps and agents hub page reference

## Structure
- Hub page that routes to three products (AI Gateway, Sandbox, eve), 10 sections: hero, 3-product "agentic infrastructure" block (each: name, one sentence, two CTAs, a mockup), a 3-item "start building" row, a Build/Run/Govern platform block, a 5-pillar security block (Identify, Protect, Detect, Respond, Recover) with linked feature lists, a 6-item use-case grid, 2 testimonials, an AI SDK block with `npm i ai`, 2 template cards, and a closing CTA pair.
- Depth: one sentence per product, one sentence per use case; the security block is the densest (each pillar lists 1 to 2 concrete features linking to docs).
- Copy to screenshots: 13 images; mockups per product (sandbox steps, eve file tree); roughly 50% copy.
- No tabs, no accordion, no FAQ.
- Hand-off: explicit. Every product tile has "Start now" + "Read the docs"/"Learn more" to /ai-gateway, /sandbox, eve.dev; security pillars link to docs pages (passport, connect, firewall, observability, audit log, attack mode, WAF rules, instant rollback, regions).
