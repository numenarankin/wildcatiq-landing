# Countries

> Reference table for all possible country codes and names returned by the API.

Below is a reference table listing all possible values that the API may return for country codes and country names. These values adhere to the [ISO 3166-1](https://en.wikipedia.org/wiki/ISO_3166-1) standard, which defines internationally recognized codes for the names of countries, territories, and special areas of geographical interest.

> [!NOTE]
>
> The full list of country codes follows the ISO 3166-1 standard. For a complete reference, see the [Wikipedia ISO 3166-1 article](https://en.wikipedia.org/wiki/ISO_3166-1).
