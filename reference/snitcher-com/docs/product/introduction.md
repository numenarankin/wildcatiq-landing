# Welcome to Snitcher

> Official documentation for Snitcher's B2B visitor identification platform. Install the tracker, integrate with CRMs, and use our APIs to identify companies visiting your website.

**Snitcher is a B2B visitor identification platform that reveals which companies visit your website.** Use this documentation to install the tracker, integrate with your CRM, and access our APIs to turn anonymous traffic into actionable leads.
