# Harvey - Knowledge product page reference

## Structure
- The shortest Harvey product page: hero, a data-partners block (partner logo list + a 500-sources line), a 4-card source grid, a 2-card "your own knowledge" group, one testimonial, closing CTA. About 5 sections, no stats row, no use-case tabs, no security block.
- Depth: one sentence per source/card. The page is mostly about *what data is connected* (named partners, EDGAR, EUR-Lex, DMS vendors) rather than workflow.
- Copy to screenshot: hero image plus one image per card; copy is sparse so images carry more weight here than on other Harvey pages.
- Tabs/accordions/FAQ: none.
- Handoff: "Vault Knowledge Bases" card hands to Vault; testimonial links to a customer story. Mega-menu and footer link siblings.
