# Giga - Agent Canvas product page reference

## Structure
- About 6 sections: hero with a three-card value strip (Built for complexity / speed / scale) and a large editor mockup, then four feature blocks each framed as "eyebrow label + H3 + 2 sentences + mockup" (Agent Builder, Built-in AI Support, Policy Writing, Simulations) grouped under two H2s, a Day 1 / Day 6 / Day 12 deployment timeline, closing CTA, compliance badges.
- Depth: each of the four features gets two sentences of copy and one full UI mockup. The mockups carry realistic content (a four-scenario banking onboarding flow with branch conditions, a Python code block for "Fetch User Profile", a test-results panel with 1,250 simulations and a 99% pass rate).
- Copy to screenshot: copy is light; mockups are large and rendered as HTML. Roughly 1:1 by count, mockups dominate by area.
- Tabs/accordions: Chat / Voice / Multi-modal selector inside the Create-agent mockup; Code / Input Schema tabs in the policy mockup. No FAQ, quotes, stats or logos.
- Handoff: Scout is written into the "Easy updates" feature ("If you can think it, Scout can do it") and into every step of the timeline, so this page sells Scout as much as Canvas.

## Section: Get a new agent up and running in no time
- Agent Builder. Effortless setup: Design new voice, chat, or multi-modal agents with as much or as little specificity as you need. Get started with transcripts, live recordings, or SOPs. - Built-in AI Support. Easy updates: If you can think it, Scout can do it. Share simple chat instructions with your built-in AI developer as you design your ideal agent. (Mockup chat: "Hello! I'm Scout, your AI developer. How can I help you today?" / "Can you add these APIs: https://docs.google.com/document" / "Great. I'll integrate those APIs and guide you through the setup.")

## Section: Control exactly how your agents show up
- Policy Writing. Precise customization: Define support rules and workflows with specificity so your agent feels like an extension of your business. (Mockup: "Fetch User Profile. Loads a user's profile from your API and stores name + tier for later steps." Tabs Code / Input Schema; callable functions APIs, Global Variables; a 20-line Python block returning store_updates and assistant_message.)
- Simulations. Refine as you go: It's easy to run test cases and iterate agent behavior for support that keeps getting better. (Mockup: Test results, Pass Rate 99%, Based on 1,250 simulations, 1,240 passed, 10 failed. Response Accuracy Test Passed 100%; User Interaction Simulation Passed 100%; AI Agent Error Handling Test Case Deviated 80%.)

## Section: How it works. Lightning-quick deployment
- Day 1, Get started: Scout ingests your past policies and auto-drafts a baseline. You review key intents and edge cases.
- Day 6, Build & Validate: Modular code + APIs deliver a review-ready version. Run manual QA; Scout refines revisions into a release-ready policy.
- Day 12, Full launch: Test-launch to 1% of call traffic, iterate with logs + feedback, then scale to 100% based on KPI insights.
