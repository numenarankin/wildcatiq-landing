## Section: FAQ (15)
Puzzle MCP:
- What is Puzzle MCP? Puzzle's server on the open Model Context Protocol standard; links accounting data to AI assistants for finance questions and delegated bookkeeping tasks.
- Which AI assistants work with Puzzle MCP? Claude (web, desktop, Claude Code), ChatGPT, Codex, Cursor, Windsurf, other MCP clients.
- How do I connect Puzzle to Claude or ChatGPT? Add Puzzle as a connector, sign in, select companies, start a new chat. Step-by-step guide provided.
- Can Claude or ChatGPT change my accounting data? Only if permitted. Read-only by default; read-write opt-in; approval checks require confirmation before changes apply; revoke any time.
- Can I connect more than one company? Yes: one, several, or all companies you manage.
- What financial data can my AI assistant access? Financial statements (balance sheet, income statement, trial balance), transactions, journal entries, chart of accounts, invoices, bills, vendors, customers, cash/burn/spending metrics.
- What accounting tasks can an AI agent do with Puzzle? Built-in skills for categorization, bill management, reconciliation, month-end close; reports such as runway, burn trends, income statement.
- How often do I need to reconnect, and are there limits? Re-authenticates every five days; high-volume use rate-limited during alpha.
- Is Puzzle MCP secure? Sign in with Puzzle account; choose companies and access level; read-write opt-in; confirmation on updates. (/security)
Puzzle API:
- What is the Puzzle API? Programmatic access to the real-time general ledger for dashboards, workflows, financial applications.
- What is the difference between the Puzzle API and Puzzle MCP? API builds accounting into your own product; MCP connects AI assistants to the live ledger.
- What endpoints are supported? Cash flow and burn rate metrics, chart of accounts, transaction history, journal entries, balance sheet and income statement reports, tax-ready summaries.
- What can I build? Embed accounting in products, automate back-office workflows, power financial dashboards. Brex, Deel, Central named.
- How do I get access? Email api@puzzle.io.
- Where is the documentation? Puzzle developer docs with endpoint references, guides, examples.
