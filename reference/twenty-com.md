## FAQ
- Is it open source? Yes. Self-host or use the managed cloud.
- Time to start? Cloud signup under a minute, 30-day trial. Larger rollouts live in 1-2 weeks with onboarding packs or partners.
- Migration? CSV or API import; partner-assisted migration available.
- Developer needed? No. Objects, fields, views, and no-code workflows configured in Settings.
- Code extensions? Yes, via the Apps framework (npx create-twenty-app), in TypeScript.
- AI tool support? Cloud workspaces include a native MCP server, connectable via OAuth.
