## Section: Works where your team already is (tabs: Slack, Email, Forms)
- Create new requests from Slack: Let anyone in your Slack workspace quickly file a request - even if they don't have a Linear account.
- Turn any email thread into an ask: Create new requests by cc'ing or forwarding to designated email addresses.
- Build custom web forms: Create internal request pages with custom forms that turn submissions into structured issues.
- Get notified about new comments and updates: Receive realtime updates on your Asks, delivered to the same channel your request came from. Mock feed: "Linear Asks 15:40 Sid Bhargava created a new Customer Bug Report: ENG-920 'Investigate missing expand control'"; "IT Helpdesk it@acme.com 14:28 An ask has been created from your email: IT-7710 'Conference room audio not working'"; "Linear Asks 09:21 Lora Baines changed status to Done for DATA-386 'New query for Sales dashboard'"; "Requests ops@acme.com 17:59 Your ask has been marked as Done: OPS-194 'Team offsite budget approval'"

## Section: How teams use Linear Asks
- Lead: Linear Asks supports all types of workplace requests. From engineering and design to IT, legal, and HR.
- Streamline bug reporting: Enable people outside of your engineering org to quickly file bug reports without worrying about complex issue details.
- Build an IT help desk: Turn any message in your #ask-IT channel into an IT ticket by reacting with an emoji.
- Escalate customer conversations: Forward emails from customers to create trackable issues when engineering support is needed.
- Standardize Ops requests: Configure templates with concrete instructions, placeholders, and checkboxes to standardize and streamline intake.
- Improve customer success: Add Linear Asks to shared Slack channels to enable your most important customers to file bug reports and feature requests.
- Manage sensitive HR tickets: Create private Asks via DM for sensitive requests that only you and your HR team can access.
