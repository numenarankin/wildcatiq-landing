# Linear - Plan (Planning and monitoring) page reference

## Structure
- One of four "pillar" pages (Intake, Plan, AI, Build) that share a template: eyebrow + two-line H1 hero with no subhead and no hero CTA, then 6 to 7 feature chapters, a 4-link pillar switcher, 3 rotating customer quotes + a scale stat, a shared closing CTA.
- Each chapter: eyebrow (feature name), two-line H2, one-sentence lead, an "X+" link to the docs for that feature, then 3 to 5 H3 sub-features (one or two sentences each) wrapped around an animated product mock whose UI text is real (status updates, Slack thread, meeting-notes doc). Some chapters use tabs (Overview / Activity / Customers / Issues; For me / Popular / Recent) or a 4-item icon list instead of H3s.
- Copy to visual ratio roughly 1:1; mocks are large. No FAQ, no pricing. Depth per feature is medium: one benefit sentence per sub-feature, with the "+" link carrying the detail.
- Hands off via the Insights chapter (arrow link to the Insights feature page) and the pillar switcher at the bottom.
