## Section: Delegate, automate, and orchestrate work (Agents)
- Lead: Build and deploy AI agents that work alongside your team. Work on complex tasks together or delegate entire issues end-to-end. Link: Agents+
- Mock: MWT-2703 Refactor sonic crawler 1 / 84
- Artificial teammates. Natural collaboration.: Linear is built for multiplayer work with AI. You can assign agents to any issue and mention them in comment threads, just like any other member of your team.
- Agents for every use case, at your command: Choose from a variety of AI agents and start delegating work, from code generation to other technical tasks. Or build your own agent.
- Orchestrate issues at scale: Delegate multiple issues in parallel and monitor the agent's progress.
- Go from issue to code instantly: Open any issue directly in your AI coding tool of choice preloaded with full context and a custom prompt.
- Backlog hygiene, automated: Keep your backlog clean and uncluttered with Linear's auto-closing and auto-archiving features.

## Section: Cycles. Build momentum with Cycles
- Lead: Cycles focus your team on what work should happen next. A healthy routine to maintain velocity and make meaningful progress. Link: Cycles+
- Modern sprint planning, purpose-built for software teams: Plan work in clear, time-boxed cycles. Linear keeps upcoming cycles ready automatically, so your team can stay focused and maintain momentum.

## Section: Linear MCP. Streamline work across tools
- Lead: Connect your toolstack to Linear via MCP and move work forward from any environment – code, design, or research – without breaking flow. Link: Linear MCP+
- Claude Code: Search, create, and update Linear issues, projects, initiatives, and more. (-> /integrations/claude)
- ChatGPT Deep Research: Surface Linear issues, projects, and discussions relevant to your context. (-> /integrations/chatgpt)
- Figma: Use the context of Linear issues to generate prototypes in Figma Make. (-> /integrations/figma-make)

## Section: Git automations. Powerful Git automations
- Lead: Link Linear with GitHub and GitLab to automate your pull request workflows. Less grunt work, less context switching, more time in flow. Link: Git automations+
- Auto-assign and update: Auto-assign issues and move them to a started status when you copy the git branch name
- Branch-specific rules: Define custom workflow automations based on specific target branches
- Link and automate PRs: Automatically change issue status based on pull/merge request updates
- PR review status: See the reviewers and review states of your pull and merge requests directly in Linear

## Section: Faster reviews, fewer bottlenecks (Diffs)
- Lead: Manage pull requests in the context of the work behind them. Review, discuss, and merge without switching tools. Link: Diffs+
- A fast and focused review experience: See every review that needs your attention in one focused interface. Open diffs instantly, respond quickly, and keep your team unblocked. Mock inbox: "Prevent duplicate trip creation, Róża requested your review, 12m"; "Remove view-mode condition, Nan approved, 1h"; "Add high contrast theme to Rider app, Andreas mentioned you: @Isha could you..., 3h"
- Review notifications you'll actually see: Never miss a review request again. Every PR notification surfaces clearly in a focused inbox built for action.
- Structural highlighting: Strip away formatting-only edits to focus on code changes, not the noise around them.
- Iterate with agents: Review feedback, resolved at agent speed. Make changes from the diff with agents and watch updates appear inline.
- Review code in context: Each diff is tied directly to the issue it resolves. No tab or tool switching required.

## Section: Reviews with direction (Guided reviews)
- Lead: Guided reviews organize diffs by showing you what's changed, and why. Review code faster by focusing on the updates that matter. Link: Guided reviews+
- A clear path through complex changes: Large PRs are hard to review without a clear way in. Guided reviews walk you through changes in semantic order, separating out supporting changes and glue code.

## Section: Releases. Release management
- Lead: Plan and track software releases. Integrates with your CI/CD tools to precisely track the deployment environment and status of every issue. Link: Releases+
- Model how each team actually ships: Create a release pipeline for every product and environment, whether continuously deployed or released on a schedule, and see every version live in one place.
