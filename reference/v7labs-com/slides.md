## Section: Have questions? (FAQ)
- How does this Slides feature fit into the rest of the V7 Go platform? Is it a standalone tool? The Slides feature is not a standalone tool; it is the integrated presentation layer that sits at the end of a workflow within the V7 Go platform. The platform's core engine is the AI Agent, which performs the heavy lifting of reading, understanding, and extracting structured insights from your complex source documents. Once the agent has completed its analysis and produced the verified data, the Slides feature takes these outputs and automatically assembles them into a polished presentation or report that adhere to your brand guidelines. Essentially, the agent provides the deep analysis, and the Slides feature builds the final, professional document.
- What types of documents can I create besides slide decks? The platform is designed to generate a wide range of professional outputs beyond slide decks. Users can configure workflows to create detailed PDF reports for audits, produce executive summaries in Microsoft Word, or automatically populate complex Microsoft Excel templates. This capability allows teams to feed structured data directly into downstream financial models or other systems, making document generation a versatile final step for any automated analysis.
- Where does the AI get the information to build these documents? Document generation is fueled by the verified insights that V7 Go AI Agents extract from your source files and Knowledge Hubs. Agents can be configured to process a wide variety of unstructured data, including investment memos in a virtual data room, folders of legal contracts, or real estate appraisals. The system uses the structured information produced during this initial analysis phase as the foundation for automatically building each new document.
- How does V7 Go ensure the generated documents match my company's branding? Brand consistency is maintained through the use of custom templates. Within the platform, teams can create and save templates that specify your organization's required fonts, color palettes, logo placements, and slide layouts. The AI generation engine uses these templates as a strict guide, ensuring that every output, whether a presentation or a report, is fully compliant with your corporate design standards and maintains a professional, on-brand appearance.
- Is this just for one-off reports, or can I automate this for recurring tasks? The document generation feature is designed for both one-off tasks and fully automated, recurring workflows. Users can configure the system to trigger an entire analysis-to-document pipeline automatically. For example, when a new Confidential Information Memorandum (CIM) is uploaded to a designated folder, an AI Agent can be set to process it and generate a standardized summary deck without any manual intervention. This is ideal for scaling recurring processes such as deal screening, compliance audits, or periodic portfolio reporting.
