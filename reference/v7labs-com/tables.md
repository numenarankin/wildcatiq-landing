## Section: Have questions? (FAQ, Contact us link)
- What is V7 Go's table interface? (published answer, mismatched: PDF, DOCX, XLSX, CSV, JPG, and PNG are supported. Each hub can contain up to 1,000 items, with virtually unlimited memory across multiple hubs.)
- How do properties work as AI-powered columns? (published answer, mismatched: Yes, you can combine SharePoint, Google Drive, and local files in the same hub if they serve the same purpose. Best practice: split hubs by company, project, or function, and don't mix unrelated files.)
- Do I need technical skills to build agents? (published answer, mismatched: RAG stops at matched text chunks. Knowledge Hubs go further, extracting OCR, tables, formulas, and visuals to provide complete, cited answers.)
- Do I have to use the table interface or is there another way to interact with V7 Go? No, you have two options. You can use the table-based agent view to configure and manage workflows, or use Cases to interact with your agents conversationally through natural language. With Cases, you simply ask questions or upload files, and the Concierge model automatically figures out which agent to use and returns results, no need to navigate the table interface. Behind the scenes, V7 Go still adds rows to your agents when processing through Cases, so both approaches work with the same underlying data.
- What happens when the AI makes a mistake or I need to correct something? V7 Go gives you several ways to catch and fix errors. It's good practice to create human-in-the-loop verification steps where reviewers can check accuracy through hyperlinked citations and interactive highlights for critical information. You can also set up an independent automated verification step that asks a different AI model to double-check the accuracy of outputs produced in previous steps. When you spot mistakes, you can simply recompute selected cells to regenerate the results. On top of that, you can provide feedback and additional instructions whenever you want to refine an answer, giving you full control over the quality of your outputs.
