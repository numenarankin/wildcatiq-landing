## Section: Have questions? (FAQ)
- What is a Skill in V7 Go? A Skill is a specialized AI capability designed to solve a specific task extremely well, such as analyzing a complex Excel model, searching regulatory filings, generating a board-ready slide deck, or redlining a contract. Each Skill focuses on one capability, and V7 agents combine them to execute larger, multi-step workflows across your tools and data.
- How are Skills different from prompts? A prompt generates a single response, while a Skill defines how a task should be executed. Skills are structured, reusable, and operational, enabling agents to follow defined steps, interact with tools, and produce consistent outputs that can be orchestrated with other Skills as part of a broader workflow.
- How do agents use multiple Skills together? Agents select and sequence Skills based on the goal they are given. Instead of producing one output, they determine which capabilities are required and in what order, chaining together research, analysis, document generation, and system updates to complete complex work end to end.
- How are Skills different from traditional workflow automation? Traditional automation relies on rigid, predefined rules, whereas Skills are AI-native and adaptive. Agents can decide which Skills are relevant, adjust their plan as they gather information, and coordinate multiple systems dynamically, making it possible to handle complex, variable work rather than fixed processes.
- Can we create custom Skills for our team? Yes, teams can define their own Skills to reflect how they operate, from preparing investment memos to generating customer follow-ups. Once created, these Skills become reusable capabilities that agents can apply consistently and combine with other Skills across the organization.
