# V7 Labs - MCP Server product page reference

## Structure
- Focused single-feature page, about 9 sections: hero, a "beyond a single prompt" demo block (Claude MCP chat mockup with three stages: Build from your SOPs / Orchestrate people, models, and systems / Run with auditability at scale), a "conversation into governed execution" 3-card block, "Automate entire business functions" intro, a 3-step connect stepper (Connect, Prompt, Build, Deploy labels; Add connector / Authorize / Run), a 4-prompt "Workflows to run" strip, a Claude-alone vs Claude-with-V7-Go comparison table, security block, closing CTA. No testimonials and no FAQ on this page.
- Depth: medium. Each of the three governed-execution cards has a bold claim plus a list of 6 to 8 concrete items (sources, workflows, example questions). The comparison table is the argument: 6 rows, two columns.
- Copy to screenshots: 6 images; text-led, with one chat mockup.
- Uses a stepper and a comparison table; no tabs, no accordion.
- Hand-off: "Read the guide" (setup guide), Security & Trust Center; implicitly positions V7 Go as "the source of truth" behind any LLM. Logo-strip tagline differs from other pages ("Shaping the future of enterprise workflow automation").

## Section: Turn conversation into governed execution
- One prompt can answer a question. V7 can automate the function behind it. Turn underwriting, deal screening, contract review, auditing, brokerage, data-room review, and corporate development into repeatable workflows with structured outputs, citations, permissions, and human review.
- Ask inside your LLM. Query V7. Get cited answers. Use your LLM to search across the full memory of your investment lifecycle: Any document, Data rooms, CRM records, IC memos, Financials, Diligence notes, Source citations, Investment memos. Your LLM becomes the interface. V7 Go remains the source of truth.
- Run workflows from any LLM. An LLM can do more than answer questions. It can trigger V7 Go workflows that follow your firm's actual process. Screen CIMs, Draft IC memos, Build tear sheets, Extract financials, Review data rooms, Create risk dashboard. Structured workflows. Run from natural language.
- Your company memory, available in every AI assistant. Instead of uploading files again, searching folders, or rebuilding context from scratch, connected LLMs can query V7 Go directly. Ask questions like: "Summarize what we know about this company." / "Pull the latest financials from the data room." / "Compare this CIM against our past IC memos." / "Find the source behind this revenue figure." Every answer stays connected to the underlying source.

## Section: Connect V7 Go to your AI assistant
- Choose your regional endpoint, authorize your workspace through OAuth, and start with a governed V7 workflow.
- 1 Add the V7 connector: Paste the EU or US endpoint from the setup guide. (Pick the V7 Go connector inside your AI assistant and give it access to the workflow environment.)
- 2 Authorize V7: Sign in with OAuth and select a V7 workspace.
- 3 Run a workflow: Ask your assistant to build, configure, or run an authorized workflow.

## Section: Workflows to run from your AI assistant
- Start with a real business process, then let V7 Go coordinate the models, knowledge, rules, and systems needed to complete it.
- Prompts: Review this insurance submission and flag missing information / Screen this opportunity against our investment criteria / Review these contracts and escalate policy exceptions / Audit this data room and produce a source-linked risk register

## Section: Comparative Benchmarks: Build workflows with LLMs, MCP clients, and AI agents
- Use the model that fits each task. V7 Go turns model reasoning into governed workflows that operate across documents, company knowledge, and connected systems, reliably, repeatedly, and at enterprise scale. (Claude, OpenAI, Gemini)
- Table: Claude alone vs Claude with V7 Go
  - Deal lifecycle coverage: One-off analysis, no pipeline vs Screening, Diligence, Monitoring
  - CIM and data room analysis: One document per conversation vs Every document, treated the same
  - Engineering dependency: You build and maintain the pipeline vs Configure fields, no code
  - Integration ecosystem: FactSet, Capital IQ, PitchBook, Office vs Same sources, plus MCP write-back
  - Time to value: Instant solo, slow to productionize vs Working pipeline the same day
  - Summary: Great assistant, nondeterministic vs Infrastructure for repeatable output
