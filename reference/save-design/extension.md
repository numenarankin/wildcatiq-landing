## Section: Answers (FAQ, 7)
- Which browsers does it work in?: Chrome, and the Chromium browsers that install from the Chrome Web Store: Arc, Brave, Edge and the like.
- Do I need a save.design account?: Yes. You sign in once in the extension, and every save goes into the workspace and folder you pick, the same workspace you use on the web.
- What does the tech stack analysis pick up?: The framework, animation libraries, fonts and more, the same breakdown the analyzer gives you. It's a checkbox, so you can save a link without it.
- How do captured sections and recordings become searchable?: Each one is analyzed when it lands and given a title and description of what's in it. So you find it later by describing it ("dark pricing table", "hover card that tilts"), not by a file name.
- How long can a recording be?: Up to 60 seconds of the area you select, without audio. You can trim it before you save.
- Are there keyboard shortcuts?: Alt+Shift+S starts a section capture and Alt+Shift+R starts a recording; press it again to stop. You can change both in your browser's extension shortcuts.
- Is it free?: The extension is free to install. Without a plan, a workspace gets a one-time allowance to try saving and analyzing, shared with the web app. Every paid plan removes the limits; Basic is $3 a month.
